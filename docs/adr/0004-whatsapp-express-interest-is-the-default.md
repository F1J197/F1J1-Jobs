# WhatsApp Express Interest is the default apply path

MyJobsFiji requires an account to apply. VitiWork's default is Express Interest: a Seeker opens WhatsApp to the Employer with no login. Application through a profile remains optional.

This is hard to reverse once Employers expect inbound WhatsApp, surprising if someone rebuilds a cover-letter wall, and a real trade-off against richer ATS tracking.

**Considered options:** profile-only apply (matches the current prototype); WhatsApp Business API as the first path (needs a human wizard later).
